# Project 1 – Statistical Digit Classification

## Overview
This project implements a statistical machine learning classifier for handwritten digit recognition. A personalized training dataset is generated using the student's ID, after which statistical features are extracted and used to classify handwritten digits.

The implementation demonstrates fundamental concepts in statistical pattern recognition, feature extraction, probability, and binary classification.

## Features
- Student-specific dataset generation
- Feature extraction from handwritten digit images
- Statistical analysis of extracted features
- Mean and variance estimation
- Binary digit classification
- Model evaluation using test datasets

## Concepts Demonstrated
- Statistical Machine Learning
- Feature Engineering
- Binary Classification
- Statistical Pattern Recognition
- Probability Theory
- Data Preprocessing
- Scientific Computing
